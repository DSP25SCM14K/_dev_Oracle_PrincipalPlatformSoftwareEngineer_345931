# Dev Kumar — Platform Software Portfolio

Static portfolio presenting platform engineering, middleware, API interoperability, multi-tenant systems, cloud reliability, and selected projects.

## Files

- `index.html` — portfolio, animated platform map, experience, projects, and publication links
- `styles.css` — responsive design, visual styling, motion and reduced-motion behavior
- `script.js` — animated background topology, rotating focus text, reveal effects, project search
- `ROLE_RESEARCH.md` — Oracle/OCI company and role research, resume evidence map, interview themes

## GitHub Pages

The site has no build step. Enable Pages from repository settings with **Deploy from a branch**, `main`, and `/(root)`.
